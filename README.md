# 現場点検ノート 試作 0.31

図面PDFに設備マーカーを配置し、設備種別に合わせた測定・指摘・写真を記録するiPad向けWebアプリの試作です。

## この試作で確認できること

- iPadの図面表示で、2本指のピンチ操作による拡大・縮小（最大500%）と、2本指での表示位置調整・1本指ドラッグによる上下左右の移動

- 図面PDFの読み込み、ページ切替、拡大縮小
- 図面上の設備をタップして記録画面を開く（移動ドラッグとは別処理）
- 標準設備アイコンの配置、ドラッグ移動、サイズ変更、45度回転、左右・上下反転
- アイコン種別の設定と、種別ごとの入力フォーム切替
- 作業区分（特定建築物調査・防火設備検査・建築設備検査・消防設備点検・消防設備修繕・調査作業・その他）の複数選択
- 作業区分と設備大分類の編集可能なマスタ、アイコンごとの大分類・対象作業の割当
- アイコン種別ごとの整理記号・色・配置時の標準サイズ設定
- 通常は1個置くと配置モードを自動解除。連続配置をオンにすると続けて置けて、ボタン・同じアイコンの再タップ・Escキーで解除
- 点検済みチェックと未点検数の表示
- 配置済み設備の複写（測定値・写真は引き継がず、種別ごとの番号候補を採番。番号は手で変更可能）
- 整理番号ラベルの位置を上下左右に調整
- 排煙窓などの不良箇所を部位選択肢または自由入力で記録
- アイコン設定で配置メニューの表示/非表示を選択
- 種別ごとに警戒番号、連動先、アドレスなど任意の追加項目を設定
- 常閉防火扉（SD）の初期アイコン
- 片扉・両扉・親子扉などの扉別測定欄
- 排煙口の縦横寸法、面積、5点風速と平均値
- 指摘区分（要是正・既存不適格・特記事項・参考・参考写真・メモ）、内容、写真の登録
- 測定・指摘/写真・配置を切り替える短い入力画面
- 参考写真・フリーメモ用アイコン
- ページ名（階数・図面名）と設置位置メモの設備一覧表示、クリックで該当ページへ移動して設備位置を一時強調
- 配置・設備一覧・ページ一覧・アイコン設定を切り替え、右パネルを閉じて図面を広く表示
- 点検期間の開始日・終了日
- 写真を長辺1200/1600/2048pxに縮小
- 速報版報告書のプレビュー（表紙・報告一覧・写真報告、3件/ページ）
- 同じ報告内容を設備種別をまたいで集約し、大分類と整理番号を記載
- 点検内容の自由入力、報告事項/指摘事項の表現切替、年月日表記
- 写真報告プレビューで不要なコマを一時削除して印刷
- 報告書の本文・場所のプレビュー編集と印刷/PDF保存
- 指摘箇所確認図でページ単位の印刷、設備ごとの表示切替、報告表示の切替、短い文言編集
- 指摘箇所に「！」、登録写真がある箇所に番号なしのカメラ印
- 指摘があるページのみ、設備マーク・整理番号・「！」・カメラ印を重ねた印刷用画面（A4横・ブラウザーからPDF保存）
- 表示中の図面ページを、アプリのメニューを除いて印刷
- 図面を全画面表示して記録位置を確認
- 写真報告書で写真コマを削除しても、残りの枠の大きさを変えない
- 案件ZIPの書き出しと、別端末での読み込み
- 整理番号順のCSV書き出し
- 入力・図面・写真を端末内のIndexedDBに自動保存
- アプリ本体をService Workerでキャッシュし、オフライン準備状態を画面表示

## iPadで使う前提

この試作はWebアプリです。PWAとして利用するにはHTTPSで配信し、iPadのSafariで一度オンライン表示してホーム画面に追加します。以後のオフライン利用は、アプリ本体をキャッシュし、図面や記録を案件ごとに端末へ保存する方式です。

ブラウザ内データだけに依存しないよう、点検後に必ず「案件を書き出す」からZIPをiPadの「ファイル」へ保存してください。別のiPadでは、同じアプリを開いて「案件を開く」からZIPを読み込みます。クラウド自動同期はこの試作には含めていません。

## オフライン確認

Windowsでは `オフライン確認手順.txt` に沿って、アプリ本体のキャッシュ後にサーバーを止めて再読み込みする確認ができます。iPadのLAN確認用HTTPアドレスではオフラインキャッシュは利用できません。iPadでのオフライン利用は、HTTPSで開ける状態にしてから確認します。

## パソコンとのデータ移動

同じアプリをパソコンでも開いて編集できますが、端末ごとに保存場所は別です。現時点では「案件を書き出す」ZIPをPC/iPad間で移す方法です。自動同期は含めていません。

## この試作に含めていない機能

不良内容の共通マスタ・物件別マスタは次の段階で追加する候補です。現場の入力項目を整理し、同じ不良内容を選択して各設備へ登録できる形を想定しています。

- 運動エネルギーおよび10J判定の本番計算式
- 提出図面上で自由に四角・丸・直線・フリー線を書き込む機能
- 注記を元PDFデータへ直接埋め込む編集（現在は印刷用の別出力です）
- 運動エネルギー計算書・測定結果一覧の報告書出力
- 正式提出図面に合わせた自由な吹き出し・図形編集
- 不良内容の共通/物件別マスタとの連動
- Dropbox / Google Drive連携
- 物件マスタを複数端末で自動同期する機能

これらは今後の追加候補です。現在の速報版は、登録済みの指摘内容と写真を使う簡易出力です。

## Windowsで確認

1. ZIPを右クリックして「すべて展開」し、`tenken-pwa`フォルダーを開きます。
2. `Windowsで動作確認.bat`をダブルクリックします。
3. PowerShellの画面に「Preview server started」と表示され、ブラウザーが開いたらPDF読み込みなどを確認します。
4. 終了時はPowerShellの画面を閉じます。

Windows標準のPowerShellを使うため、Pythonのインストールは不要です。サーバー起動時のエラーは画面に表示されます。

## iPadで使う場合

このZIPのフォルダーをiPadの「ファイル」に置くだけでは、アプリとして動作しません。HTTPSで配信したURLをSafariで開き、ホーム画面に追加する準備が別途必要です。Windowsの確認用URL（127.0.0.1）はそのWindows PC内だけで使うものです。

## 開発用プレビュー

WindowsまたはMacのパソコンでフォルダーを開き、ローカルHTTPサーバーで `index.html` を表示するとプレビューできます。PWAのService Workerは安全な配信元（HTTPSまたはlocalhost）で有効になります。初回に開いた後、画面右上に「オフライン準備OK」と表示されたことを確認してから、ブラウザの通信を切って動作を確認してください。iPadの確認用LANアドレス（http://PCのアドレス:8766）はHTTPのためService Workerが無効になり、画面に「HTTPSが必要」と表示されます。iPadのオフライン試験は、HTTPSで公開した後に行います。

PDF.js（Mozilla）およびJSZipのライセンス情報は `vendor/` に同梱しています。

## 0.23の変更
- 提出用図面の設定画面を追加しました。設備や報告文を個別に表示/非表示にできます。
- 図面に表示する短い報告文を編集できます。
- 設備や報告文の表示を設定し、元PDFに重ねた印刷用プレビューを作成できます。

## 0.24の変更
- 印刷対象を、報告内容があるページだけに絞りました。
- 図面上に整理番号を表示し、報告箇所には「！」、写真がある箇所には番号なしのカメラ印を表示します。
- 初期状態では報告が登録されている設備だけを表示します。必要に応じて他設備も含められます。
- 写真番号は付けず、位置確認用の図面として印刷する形にしました。

## 0.25の変更
- 表示中の図面ページをアプリの操作メニューなしで印刷できるようにしました。印刷時は図面と配置アイコンを合わせて縮小し、用紙内に収めます。
- 図面を全画面表示するボタンを追加しました。もう一度×を押すと通常表示に戻ります。
- 速報版写真報告書でコマを削除した後、残りの写真枠が縦に伸びてレイアウトが崩れる問題を修正しました。

印刷はアプリ画面の現在ページをブラウザーから出力する簡易機能です。プリンターや用紙設定によって余白・縮尺が変わることがあるため、提出前に印刷プレビューを確認してください。元PDFへの直接書き込みではなく、表示中のPDFページとアイコンを重ねて印刷します。

## 0.26の変更
- 案件ZIP読込時に「案件を開く」と「次回点検用に複写」を選べます。
- 次回点検用の複写では、点検済み・測定値・写真を個別にリセットできます。設備配置、高さ・幅、注意点、指摘文は保持します。
- 案件ZIP名に点検開始日（yymmdd）と物件名を含めます。

## 0.27の変更
- 基本設定から環境設定をJSONで読み込み・書き出しできます。読み込んだ設定は端末に保存し、次に作る新規案件から使います。
- 現在案件のマスタを新規案件の初期設定として保存できます。既存案件の設定・点検記録は読み込みで変更しません。
- アイコン設定で台数集計の初期値を指定でき、個別の設備ごとにも集計対象を切り替えられます。
- ページ別数量と数量CSVは、台数集計から外した設備を除外します。
- `環境設定_消防設備向け基本パック.json`を同梱しました。消火器・屋内消火栓・感知器・発信機・誘導灯・避難器具などのアイコンを含む編集用のたたき台です。


## 0.29の変更
