# 現場点検ノート 試作 0.52

PDF図面上に設備を配置し、測定・指摘・写真を記録するWindows／iPad向けWebアプリです。ビルド不要の静的構成です。

## v0.52：設備ごとの常用ボタン

「指摘・写真」でよく使う指摘を1タップ登録できます。ボタンは設備種別ごとに設定し、区分・概要・補足・備考／改善提案を持たせます。登録後の文言修正・部位指定・写真追加は通常どおりです。

最初は常用未登録です。次のいずれかで追加してください。

1. 設備を開き、不備内容を入力 →「☆ 常用に追加」→ ボタン名を入力。
2. 環境設定 → 設備アイコン設定 → 対象のアイコンを編集 →「常用ボタン（よく使う指摘）」→ 追加して保存。

常用からの指摘追加時は入力中の設備情報も案件へ保存します。同じ内容がある場合は二重追加せず、既存の記録を表示します。常用そのものを削除しても登録済みの指摘は残ります。

対象の作業区分を選べば、建築側・消防側などのボタンを分けられます。ボタン側が無選択なら共通、案件側が無選択ならその設備の全ボタンを表示します。アイコン自体の対象作業区分も必要に応じて設定してください。

## 常用を新しい案件でも使う

登録・編集した常用は現在の案件の設定です。環境設定で「今の設定を初期設定にする」を押すと、次の新規案件でも使えます。「書き出す」でJSONに保管でき、他端末へも渡せます。JSON読込は次の新規案件から適用されます。現在の案件へ自動で一括上書きはしません。

案件ZIPには常用設定と登録済みの指摘が含まれ、次回点検用複写でも引き継ぎます。

## 更新方法

更新前に案件ZIPと環境設定JSONを保管してください。従来と同じGitHub Pages公開フォルダへアプリ一式を利用者が反映し、画面上部の **0.52** を確認します。こちらから公開先は変更していません。

今回のキャッシュ名は `tenken-shell-v48`。初回はオンラインで「オフライン準備OK」を確認します。通常の更新でサイトデータ・IndexedDBを削除する必要はありません。

Windowsは「Windowsで動作確認.bat」、iPadのLAN確認は「iPadで試す手順.txt」、オフラインは「オフライン確認手順.txt」を参照してください。iPadのオフライン利用はHTTPSで配信します。

## 保存と確認範囲

案件・図面・写真はIndexedDB、環境設定の初期値はlocalStorageへ保存します。自動クラウド同期はありません。プレビュー上の編集は報告書だけの一時編集なので、残したい文章は設備の入力画面で保存してください。

構文・DOM操作・データ処理に加え、ChromiumでPDF読込・設備配置・常用追加・報告集約・保存・オフライン再起動を確認しました。PC・タブレット・スマートフォン相当の画面幅も確認済み。iPad実機／Safari・Windows実機・印刷は未確認です。

詳細は「第2フェーズ引継ぎ.md」と「更新内容と確認手順.txt」を参照してください。PDF.jsとJSZipのライセンスは `vendor/` に同梱しています。
