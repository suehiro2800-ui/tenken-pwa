# 現場点検ノート 試作 0.55

PDF図面に設備を配置して測定・指摘・写真を記録する、Windows／iPad向けWebアプリです。ビルド不要です。

## v0.55：配置パレットと作業区分を分離

配置アイコンは「★常用／全て／アイコン分類」で選びます。基本設定の作業区分を変更してもパレットの設備は隠れません。「配置メニューに表示」の有効・無効は引き続き反映します。

アイコン編集の「対象となる作業区分」は不要になったため画面から外しました。旧データは保持します。「指摘・写真」の常用ボタンに対する作業区分設定は従来どおりで、速報版報告書の作業区分も作成時に独立して選択できます。

配置アイコンの一括削除・複数選択削除を今後の改修計画へ追加しました。フロアノートの空きタイルへのリセットとは別機能です。今回の版では未実装です。

以下は各版当時の説明です。v0.53の作業区分によるパレット絞込みは、v0.55では行いません。

## v0.54：アイコン分類の編集と☆常用登録

環境設定 →「アイコン分類（パレット）」で分類を追加・名前変更・削除できます。削除時は所属アイコンの移動先を選びます。分類の目印色も設定できます。分類名と報告書の設備大分類は別です。

アイコン編集の分類を変更すると目印色を背景色の初期値とし、文字色も調整します。背景色・文字色は個別に変更できます。分類名・目印色を編集しただけでは既存アイコンの背景色を変更しません。

パレットの☆で常用登録、★で解除できます。星を押しても配置は始まりません。設定は現在の案件に保存されます。別の新規案件の初期値にするには、環境設定パックの「今の設定を初期設定にする」を実行し、JSONも書き出して保管してください。

分類の追加・削除・所属、常用、並び順は案件ZIPと環境設定JSONに含みます。旧案件の4分類も引き継ぎます。フロアノート本体とレポート出力は今後の開発です。「今後の構成案.md」を参照してください。

以下のv0.53節は当時の実装説明です。現在は固定4分類ではなく、上記の分類マスタを使用します。

## v0.53：パレットの分類・常用・並べ替え

パレット上部で「★常用／全て／扉・シャッター／排煙設備／非常灯／その他」を切り替えます。分類はアイコン設定の「色分け（パレット分類）」を使用します。

起動や案件読込後は「★常用」を表示します。初期の常用は特記事項・参考写真・フリーメモ。任意のアイコンを、環境設定 → 設備アイコン設定 → 編集の「常用パレットに表示」で追加・解除できます。

順番は、環境設定 → 設備アイコン設定の一覧にある↑↓で変更します。各分類や常用でも同じ順序を使います。設定は案件ZIPと環境設定JSONへ保存されます。新規案件でも使うには「今の設定を初期設定にする」を実行してください。

v0.55では、作業区分によるパレットの絞込みはありません。アイコンが見つからない場合は「全て」と配置メニューの表示設定を確認してください。

## 新しい扉種別の測定欄

入力画面が「扉測定」なのに測定部位が空の場合、寸法・閉鎖時間等が表示されない問題を修正しました。新規、既存の空部位、複写にも対応します。

色分けが「扉・シャッター」でも、入力画面が「一般記録」なら測定欄は出ません。アイコン編集の「タップしたときの入力画面」で「扉測定」を選んでください。

今回追加したのは測定欄の補完です。運動エネルギー・10J計算は未実装です。報告された既存の計算項目については測定画面のスクショ等で照合が必要です。

## v0.52の常用ボタンも使用できます

設備の「指摘・写真」でよく使う指摘を1タップ登録します。入力済み指摘の「☆ 常用に追加」、またはアイコン編集の「常用ボタン（よく使う指摘）」から設定します。これは指摘文用の常用で、設備パレットの常用とは別です。

## 更新と保存

案件ZIPと環境設定JSONを保管してから、従来のGitHub Pages公開フォルダへアプリ一式を反映し、上部「0.55」を確認してください。こちらから公開先は変更していません。

キャッシュは `tenken-shell-v51`。初回はオンラインで「オフライン準備OK」を確認します。通常の更新でサイトデータ・IndexedDBを削除する必要はありません。

Windowsは「Windowsで動作確認.bat」、iPadのLAN確認は「iPadで試す手順.txt」、オフラインは「オフライン確認手順.txt」を参照してください。iPadのオフライン利用はHTTPS配信が必要です。

案件はIndexedDB、環境設定の初期値はlocalStorageに保存します。自動クラウド同期はありません。プレビュー編集は一時的なので、残したい文章は設備の入力画面で保存してください。
