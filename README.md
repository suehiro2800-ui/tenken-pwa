# 現場点検ノート 試作 0.51

PDF図面上に設備を配置し、測定・指摘・写真を記録する、Windows／iPad向けWebアプリです。ビルドは不要です。

## v0.51の修正

フォーム外の背景をタップしても入力画面が閉じないようにしました。環境設定、アイコン編集、速報版設定、設備の記録画面など、共通の入力フォームへ適用しています。「保存」「閉じる」「×」等の明示的な操作は従来どおり使用できます。

今回の変更はフォーム外のタップによる終了だけを防ぐものです。入力の保存方法は各画面で従来どおりです。

## v0.50の追加内容

各設備の「指摘・写真」画面に、**備考・改善提案（任意）** の自由入力欄を追加しました。バッテリー交換、本体交換、調整・修理などを、不備の概要や補足とは別に記録できます。文例を選ぶ必要はなく、空欄・複数行にも対応します。

この入力は写真報告書の「備考」へ表示します。同じ不備に写真が複数あれば、各写真コマに同じ内容を載せます。案件保存・案件ZIP・次回点検用複写にも内容を引き継ぎます。測定一覧CSVでは末尾に改善提案の列を追加しています。

旧案件で備考に表示していた文章は、入力欄と写真報告書へ引き継ぎます。不要なら入力欄を空にして保存してください。その後は不備の補足から備考を自動補充しません。

文例参照と設備ごとの整理記号・番号サイズ調整は保留課題です。文字サイズの自動拡大はv0.49を維持しています。

## v0.49の修正も含みます

オフライン準備表示、本文未入力の要是正等がある時の「異常なし」判定、設定チェック欄、図面ラベルの拡大、速報版のNo.表記と箇所数編集、環境設定の初期適用、現地日付等の修正を引き継いでいます。

## 更新と確認

更新前に現在の案件ZIPと環境設定JSONを保管してください。GitHub Pagesへは従来の公開フォルダにアプリ一式を利用者が反映し、画面上部の **0.51** を確認します。今回こちらから公開先は変更していません。

キャッシュ名は `tenken-shell-v47`。初回はオンラインで読込み「オフライン準備OK」を確認します。端末内の案件を保持するため、通常の更新でサイトデータやIndexedDBを削除する必要はありません。

Windowsは「Windowsで動作確認.bat」、iPadのLAN確認は「iPadで試す手順.txt」、オフラインは「オフライン確認手順.txt」を参照してください。iPadのオフライン利用にはHTTPSでの配信が必要です。

## 保存と出力の違い

案件・図面・写真はIndexedDB、環境設定の初期値はlocalStorageに保存します。自動クラウド同期はありません。案件ZIPと環境設定JSONは別々に保管してください。

案件へ残す改善提案は「指摘・写真」の入力画面で保存してください。速報版プレビュー上で直接編集した文言や箇所数は、その報告書だけの一時編集です。再生成すると案件の記録に戻ります。

詳しい状態・継続課題は「第2フェーズ引継ぎ.md」、今回の操作例は「更新内容と確認手順.txt」にまとめています。運動エネルギー計算、改善提案の文例参照、自由な図形注記、原寸PDF出力は未実装です。

構文検査と架空データによる保存・報告書生成・ZIP等の処理確認は実施済み。実ブラウザーの表示、iPad／Safari、印刷、実際のオフライン起動は未確認です。

PDF.js（Mozilla）とJSZipのライセンスは `vendor/` に同梱しています。
