## v0.60：速報版と写真報告書への掲載を個別に選択

「指摘・写真」の各記録に「報告書への掲載」を追加しました。「速報版」「写真報告書」をそれぞれ選べます。両方を外しても、元の記録・写真は残ります。写真を付けていない記録から写真のコマは作りません。

「環境設定 → 調査区分の選択ボタン → 報告書への掲載初期設定」で、区分ごとの初期値を変更できます。変更は新しい記録へ適用し、登録済みの指定は変えません。個別指定する前の区分変更では初期値を適用し、個別指定した後は区分を変えてもその指定を保持します。「区分の初期設定を適用」で戻せます。

旧案件の掲載は従来どおりです。要是正・既存不適格は、速報版から外しても「異常なし」にはなりません。速報版は掲載対象だけを集約して箇所数を数え、写真だけ載せる記録は「写真○」と表示します。フロアノート・議事録・確認図・CSVはそれぞれの出力設定を使います。

個別指定を案件ZIPへ、区分別初期設定を案件ZIPと環境設定JSONへ保存します。新しい案件でも使うには「今の設定を初期設定にする」を実行してください。この機能を含むZIPはv0.60以降で開いてください。詳しい確認手順は同梱の「更新内容と確認手順.txt」を参照してください。

## v0.57：編集して保存できる調査レポート・写真一覧・議事録・借用物

フロア別レポートは文章形式を基本にし、「調査趣旨・概要・結果・所感」と登録内容を整理します。写真は本文の後に2列×3段の一覧で出力。4枚／ページや従来の一覧表も選べます。

本文・写真説明・コメントは出力画面で直接編集し、「編集内容を保存」で案件へ保存します。再度開いたときも編集を続けられます。保存先はレポート用の文章で、測定値や指摘の原記録は変更しません。登録内容から作り直したい場合は、レポート作成時に保存内容を使うチェックを外します。空欄の調査趣旨・概要・所感等は印刷時に省略します。

フロアノートの「＋ 議事録メモ」から、1議題1アイコンで日付・参加者（敬称略）・議題・内容を記録できます。「議事録」専用タブと「写真・補足」タブを用意しました。「この議事録だけを出力」で単独の議事録と添付写真を出力し、出力文章を編集・保存できます。

現場管理モードのパレット上部には「担当者・あいさつする場所」「いつも借りるもの」「いつもの作業の流れ」「当日の注意点」の4欄を表示します。各欄をタップして編集でき、案件とZIPに保存します。通常情報は次回複写にも引き継ぎ、当日の注意点を空にするかは複写時に選べます。

現場管理モードにも「議事録」と「借用物」を追加しました。「鍵」も借用・返却の専用入力へ変更し、名称・数量・相手・借用日時・返却状態・返却日時・写真を残せます。現場一覧で返却状態を確認できます。旧鍵マークの完了を、返却済みへ自動変換しません。

案件ZIPに議事録・現場写真・返却記録・レポート編集も含みます。新機能を含むZIPはv0.57以降で開いてください。次回点検用の複写では出力用の下書きを外し、写真リセットを選べば現場写真も外します。借用物の実際の返却履歴は維持します。

以下は各版当時の説明です。

## v0.56：環境設定への集約とフロアノート

案件の作業区分の変更欄を「環境設定 → この案件の作業区分」へ移しました。新規案件で仮設定し、後からここで変更できます。指摘文の常用ボタンと速報版の初期値に使う仕様は従来どおりです。「基本設定」タブは「フロアノート」へ置き換えました。

フロア名と空き枠数を設定し、図面なしで設備・測定・指摘・写真を記録できます。空き枠をタップし、常用／全て／分類から設備を選びます。1フロアは最大240枠。後から枠を追加でき、登録済みの設備は検査一覧にも表示します。同じ案件内でPDF図面とも併用できます。

登録内容は1件・選択した複数件・現在フロア全体を空き枠へ戻せます。直前のリセットはアプリを開いている間だけ戻せます。リセット済みの枠を再使用した場合は上書き復元しません。図面の配置アイコンの一括・選択削除は今後の課題で、この機能とは別です。

「フロア別レポート」は、対象フロア、整理番号順／設備名順／枠順、測定・追加項目、調査内容、写真ページの掲載を選べます。空き枠を除外した一覧と1ページ3枚の写真を、印刷／PDF保存できます。メモも選択した調査内容に含めます。既存の速報版にもノートの報告対象記録が入り、指摘箇所確認図には図面の記録だけが入ります。

フロア・枠・測定・写真は案件ZIPへ含めます。写真の名前はフロア・場所・設備等を付けます。フロアを含むZIPはv0.56以降で開いてください。施工前中後の専用選択肢、アイコン別の表示部品は今後の改修です。写真／速報の個別掲載指定はv0.60で追加しました。

## v0.54：アイコン分類の編集と☆常用登録

環境設定 →「アイコン分類（パレット）」で分類を追加・名前変更・削除できます。削除時は所属アイコンの移動先を選びます。分類の目印色も設定できます。分類名と報告書の設備大分類は別です。

アイコン編集の分類を変更すると目印色を背景色の初期値とし、文字色も調整します。背景色・文字色は個別に変更できます。分類名・目印色を編集しただけでは既存アイコンの背景色を変更しません。

パレットの☆で常用登録、★で解除できます。星を押しても配置は始まりません。設定は現在の案件に保存されます。別の新規案件の初期値にするには、環境設定パックの「今の設定を初期設定にする」を実行し、JSONも書き出して保管してください。

分類の追加・削除・所属、常用、並び順は案件ZIPと環境設定JSONに含みます。旧案件の4分類も引き継ぎます。フロアノート本体とレポート出力は今後の開発です。「今後の構成案.md」を参照してください。

## v0.53：パレットの分類・常用・並べ替え
