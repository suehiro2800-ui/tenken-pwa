# 現場点検ノート 試作 0.49

PDF図面上に設備を配置し、測定・指摘・写真を記録する、Windows／iPad向けWebアプリです。ビルドは不要です。

## 今回の変更

- オフライン準備表示が確認するキャッシュ名を、実際の保存先と一致させました。
- 概要・本文が未入力の要是正／既存不適格も異常の記録として扱い、「異常なし」を選べないようにしました。速報版では「内容未入力（要確認）」を表示します。
- アイコン設定・速報版設定などのチェックボックスの幅を調整し、作業区分名の縦折返しを改善しました。
- 図面上の整理記号・番号が拡大率に合わせて11〜22pxで変わるようにし、アイコン中心を基準に上下左右へ表示します。
- 速報版一覧の見出しを「No.」に変更し、箇所数をプレビューで編集できるようにしました。
- 保存案件なしの起動・案件削除後にも環境設定のアイコンを引き継ぎます。
- 「注意点」など設定に含まれる区分を指摘入力画面にも表示します。
- 新規案件の日付は端末の現地日付で初期設定します。
- 確認図用の文言が未設定で概要が空の場合は、備考を表示文として使います。意図的に空にした確認図用文言は保持します。

## 利用方法と更新

Windowsでは、展開したフォルダの「Windowsで動作確認.bat」を実行してください。iPadのLAN確認方法は「iPadで試す手順.txt」、オフライン確認の説明は「オフライン確認手順.txt」を参照してください。

iPadでのオフライン利用にはHTTPSでの配信が必要です。GitHub Pagesへは利用者が本ZIP内のアプリ一式を更新します。画面上部に **0.49** が表示されることを確認してください。今回のキャッシュ名は `tenken-shell-v45` です。

公開先のURL・公開フォルダは従来のままにし、更新前に現在の案件ZIPと環境設定JSONを書き出してください。更新後の最初の読込はオンラインで行い、「オフライン準備OK」を確認します。端末内の案件を保持するため、通常の更新ではサイトデータ・IndexedDBの削除は不要です。

## データと出力

案件・図面・写真は端末内のIndexedDB、環境設定の初期値はlocalStorageへ保存します。自動クラウド同期はありません。案件ZIPと環境設定JSONは別々に書き出して保管してください。

速報版プレビューの編集は生成した報告書にのみ反映されます。箇所数の手修正も原記録や数量集計を変えず、プレビューを作り直すと自動集計に戻ります。

詳しい実装状況と未完了項目は「第2フェーズ引継ぎ.md」、今回の確認手順は「更新内容と確認手順.txt」を参照してください。運動エネルギー計算、改善提案の独立入力・文例参照、自由な図形注記、原寸PDF出力はまだ実装していません。

## 確認範囲

構文検査と、架空データによる報告書生成・集約・ZIP・次回複写・設定適用等の処理確認を実施しました。実ブラウザーの描画確認、iPad／Safari操作、印刷、Service Workerによる実際のオフライン再起動は未確認です。

PDF.js（Mozilla）とJSZipのライセンスは `vendor/` に同梱しています。
